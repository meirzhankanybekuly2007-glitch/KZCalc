# KZCalc — калькуляторы Казахстана

Статический сайт на HTML/CSS/JavaScript, готовый для GitHub Pages.

## Запуск локально
1. Откройте `index.html` двойным кликом или используйте VS Code + Live Server.
2. Для GitHub Pages загрузите содержимое этой папки в Public repository.
3. Settings → Pages → Deploy from a branch → `main` → `/root` → Save.

## Обновление
Основные показатели 2026 года находятся в объекте `RATES` в `js/app.js`.
Перед публикацией финансовых/налоговых расчётов сверяйте значения с официальными источниками.
